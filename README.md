## Responsive Next.js-TS + Tailwind Portfolio Template
A modern, fully responsive portfolio template built with Next.js, TypeScript, and Tailwind CSS.
Designed for developers, designers, freelancers, and creative professionals who want to showcase their skills, projects, and experience with a clean and professional online presence.

## Features

🎨 Modern and clean UI design

📱 Fully responsive across all devices

⚡ Built with Next.js and TypeScript

🎯 Tailwind CSS for fast and efficient styling

🔍 SEO-friendly structure

## Getting Started

npm run dev
